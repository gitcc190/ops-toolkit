# 主机清单示例
#
# 用法：
#   python3 python/batch_ssh.py -H hosts.txt -c "uptime" -k ~/.ssh/id_ed25519
#
# 格式（三种都支持，用户名可选）：
#   192.168.1.11                 用 -u 指定的全局用户名
#   192.168.1.11:2222            指定端口
#   lw@192.168.1.11:2222         逐台指定用户名（推荐，混用账号时必需）
#
# 空行与 # 开头的行会被忽略。
# 真实清单存 hosts.txt（已在 .gitignore 里），仓库只提交本示例文件。

# ---- 本项目的实验环境 ----
# 用户名不同时，必须在清单里逐台写 user@host，否则 -u 只能覆盖其中一类
lw@192.0.2.11
kali@192.0.2.12
